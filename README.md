# ADV SRL — Sitio web

Sitio institucional de **ADV SRL**: logística integral con flota propia, alquiler de maquinaria pesada con operador, movimiento de suelos, obras de infraestructura y almacén propio para minería.
San Fernando del Valle de Catamarca.

Sitio estático (HTML + CSS + JS), sin dependencias. Para verlo, abrir `index.html` en el navegador.

## Estructura
- `index.html` — página única con todas las secciones (nosotros, números, pilares, flota y equipos, almacén, cobertura, coordinación, habilitaciones, minería, casos, cotización, contacto)
- `css/styles.css` — estilos y responsive
- `js/main.js` — animaciones, menú, contadores, pestañas de flota/equipos, galería y formulario de cotización (envío por WhatsApp)
- `assets/img/` — imágenes

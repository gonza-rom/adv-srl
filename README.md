# ADV SRL — Sitio web

Sitio institucional de **ADV SRL**: hormigón elaborado, bombeo, laboratorio y asesoramiento técnico.
San Fernando del Valle de Catamarca.

Sitio estático (HTML + CSS + JS), sin dependencias. Para verlo, abrir `index.html` en el navegador.

## Estructura
- `index.html` — página única con todas las secciones
- `css/styles.css` — estilos y responsive
- `js/main.js` — animaciones, menú, galería y formulario de presupuesto (envío por WhatsApp)
- `assets/img/` — imágenes

## Datos a editar
- Número de WhatsApp: `js/main.js` (constante `WHATSAPP`) y links `wa.me` en `index.html`.
